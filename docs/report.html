Project summary

The service provides addition, subtraction, multiplication, and division through REST endpoints. It accepts decimal operands, returns a JSON result, rejects missing or invalid parameters with structured HTTP 400 errors, and exposes Spring Actuator health status.

The deployment uses two Compose services. The calculator runs on the private Compose network; Nginx provides the browser and API entry point. Both services have health checks and restart policies. The application image uses a Maven build stage and a smaller Java runtime stage, runs as a non-root user, and exposes port 8081 inside the container.

Observed local deployment: On 30 October 2026, the calculator and Nginx services were running and reported healthy. Port 8082 was unavailable, so the existing proxy was accessible at http://localhost:8083. The health endpoint returned {"status":"UP"}; the add endpoint returned a result of 5 for 2 + 3.

Architecture

Developer push to GitHub │ ▼ Jenkins Multibranch Pipeline Checkout → Build → Test/JUnit → Package → Docker Build │ main branch only ├── Push tagged image to Docker Hub └── Compose deploy → Calculator ──private network── Nginx proxy │ │ /actuator/health browser/API entry

The pipeline and deployment are configured in the project files. A successful Jenkins execution and external service configuration must be demonstrated separately; this report does not claim a completed Jenkins run.

Pipeline stages

StageWhat the project configures
CheckoutChecks out the revision supplied by the Jenkins multibranch job.
BuildRuns Maven clean package with tests skipped in this stage.
TestRuns Maven tests and publishes Surefire JUnit XML reports.
PackagePackages the executable JAR and archives it in Jenkins.
Docker BuildBuilds a branch/build-number tagged calculator image and the Nginx proxy image.
PushOn the main branch, authenticates with Jenkins-managed credentials and pushes the versioned and latest Docker Hub tags.
DeployOn main, deploys through Compose and waits for service health checks.
NotificationsJenkins post actions send success/failure email through the configured Email Extension settings.
